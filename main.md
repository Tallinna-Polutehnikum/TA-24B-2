    The main project - "Apollo Kino" website. Made by Samir 'Miles' Cibis, Aleksander 'ThePanshurup' Kartuzov and Daniel Helmrosin.

    In this document we will show which stackes we used for the project and explain which features we will add to our project.

    You can view the guide how to run a project in the *guide.md*

    You can see the update logs in the *update-log.md*

## Stacks used:
    - Node.js
    - NestJS
    - MikroORM
    - MySQL 8.4
    - Vue 3 + Vite
    - PrimeVue

## What already works:
    - NestJS backend starts on port 3000.
    - MySQL runs with Docker Compose.
    - MikroORM connects to MySQL and creates/uses the `movie` table.
    - Backend seeds five demo movies on first start.
    - `GET /movies` returns movies from MySQL.
    - Vue + PrimeVue frontend loads those movies from the backend and displays them as cards.
